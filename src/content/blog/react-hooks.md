## 为什么需要稳定的心智模型

Hooks 的价值不只是把逻辑写进函数。更重要的是，它让组件的状态、外部同步和副作用拥有清晰的边界。

## 依赖数组应该表达什么

依赖数组描述的是“这个副作用读取了哪些会变化的值”。它不是一个让代码停止运行的开关。先写出副作用实际读取的值，再决定是否需要拆分副作用，通常比关闭 lint 规则更可靠。

```ts
useEffect(() => {
  document.title = `${count} unread messages`;
}, [count]);
```

## 抽象的边界

只有当一段逻辑在两个以上场景中拥有相同的生命周期语义时，才值得抽成自定义 Hook。过早抽象会让调用者难以理解数据从哪里来，也让调试路径变长。

好的抽象会隐藏实现细节，同时清楚地表达输入、输出和副作用。
