## 项目背景

作品集需要同时服务招聘者和长期写作，因此页面结构与内容数据保持分离。

## 我的贡献

负责架构、设计系统、内容集合和静态部署流程，确保新增文章或项目只需要添加内容文件。

## 项目亮点

- 静态生成，首屏无需客户端框架。
- Markdown 内容通过 schema 校验。
- GitHub Actions 自动构建并发布到 Pages。
