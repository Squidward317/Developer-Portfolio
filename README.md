# Developer Portfolio

基于 Astro、TypeScript、Tailwind CSS 和 Markdown Content Collections 构建的个人开发者作品集。

## 本地开发

```bash
pnpm install
pnpm run dev
```

生产构建：

```bash
pnpm run check
pnpm run build
pnpm run preview
```

## 内容维护

- 个人资料：`src/data/profile.ts`
- 技能、经历和教育：`src/data/portfolio.ts`
- 博客：`src/content/blog/`
- 项目内容：`src/content/projects/`
- 内容 schema：`src/content.config.ts`
